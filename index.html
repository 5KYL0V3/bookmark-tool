📂 书签 HTML 生成器（书签栏优先版）

这个工具用于把整理好的 CSV 书签数据重新生成浏览器可导入的 HTML 书签文件。 生成文件会使用 PERSONAL_TOOLBAR_FOLDER 标记，尽量让浏览器识别为“收藏夹栏 / 书签栏”。 但最终导入位置仍可能受浏览器策略影响。

推荐输入格式：
大类,小类,网站标题,备注说明,网络预警,网址
网络预警建议使用：国内直连、需翻墙、访问慢
已兼容网址格式：https://xxx.com 和 [https://xxx.com](https://xxx.com)
📌 书签结构预览
使用方法：生成并下载 HTML 文件后，在 Chrome / Edge 中进入书签管理器，选择“导入书签”，再选择下载的 HTML 文件。
