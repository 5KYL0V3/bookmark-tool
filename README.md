# 书签 HTML 生成器

一个轻量级的浏览器书签整理工具，用于把整理好的 CSV 书签数据转换成浏览器可导入的 HTML 书签文件。

在线访问地址：

https://zhang-obbs-app.netlify.app/

## 项目简介

这个项目主要用于整理浏览器书签。

它可以读取指定格式的 CSV 文本，按照“大类 / 小类 / 网站标题 / 备注说明 / 网络预警 / 网址”的结构重新生成浏览器书签文件，方便导入 Chrome、Edge、Firefox 等浏览器。

生成的文件采用 Netscape Bookmark HTML 格式，并使用 `PERSONAL_TOOLBAR_FOLDER` 标记，尽量让浏览器识别为“收藏夹栏 / 书签栏”。

需要注意的是，不同浏览器对书签导入位置的处理策略不同，因此最终导入位置可能仍由浏览器决定。

## 主要功能

* 支持将 CSV 数据转换为浏览器书签 HTML
* 支持按照大类和小类自动生成书签文件夹
* 支持生成“书签栏优先”的 HTML 书签文件
* 支持重复链接检测和去重
* 支持无效行提示
* 支持处理结果统计
* 支持书签结构预览
* 支持复制生成结果
* 支持下载生成后的 HTML 文件
* 支持普通网址格式
* 支持 Markdown 链接格式，例如 `[https://example.com](https://example.com)`

## 输入格式

推荐输入 CSV 格式：

```csv
大类,小类,网站标题,备注说明,网络预警,网址
工具,图像处理,Bigjpg,基于人工智能的图片无损放大工具,国内直连,https://bigjpg.com/
开发,代码托管,GitHub,全球最大的开发者社区及代码管理平台,访问慢,https://github.com/
```

字段说明：

| 字段   | 说明               |
| ---- | ---------------- |
| 大类   | 书签的一级分类          |
| 小类   | 书签的二级分类          |
| 网站标题 | 网站名称             |
| 备注说明 | 网站用途简介           |
| 网络预警 | 国内直连 / 需翻墙 / 访问慢 |
| 网址   | 网站链接             |

## 使用方法

1. 打开网页工具。
2. 将整理好的 CSV 数据粘贴到输入框。
3. 点击“修复并生成”。
4. 检查处理统计和书签结构预览。
5. 点击“下载 HTML 文件”。
6. 在浏览器中导入下载的 HTML 书签文件。

## 浏览器导入方法

以 Edge / Chrome 为例：

1. 打开浏览器书签管理器。
2. 找到“导入书签”或“导入收藏夹”。
3. 选择刚刚下载的 HTML 文件。
4. 等待浏览器完成导入。

## 注意事项

* 请尽量保证输入数据是标准 CSV 格式。
* 每行建议保持 6 列。
* 网址建议放在最后一列。
* 如果网络预警字段不是“国内直连 / 需翻墙 / 访问慢”，工具会默认按“访问慢”处理。
* 完全相同的网址会被去重，只保留第一次出现的记录。
* 生成的书签文件导入位置可能受浏览器策略影响，不一定百分百进入书签栏。

## 隐私说明

本工具在浏览器本地运行。

输入的 CSV 数据不会上传到服务器，也不会发送到第三方接口。
所有处理过程都在当前浏览器页面中完成。
